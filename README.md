# bubblegno.xyz

Bubble map for [gno.land](https://gno.land) — addresses & realms as bubbles, transfers / `MsgCall` as links. Inspired by [Bubblemaps](https://v2.bubblemaps.io/).

**Live:** [bubblegno.xyz](https://bubblegno.xyz) · API `api.bubblegno.xyz`

**Stack:** Go watcher + HTTP API · Dgraph · Onbloc GraphQL (`gnoland-1`) · Vite front on Vercel · API image on GHCR → DigitalOcean droplet.
